    """เช็คว่าปัจจุบันเลยเวลาตลาดหุ้นนิวยอร์กปิด (16:00 น.) แล้วหรือยัง"""

# 3. ฟังก์ชันคำนวณทางเทคนิคและอุดรอยรั่ว
# ==========================================
def calculate_rsi(prices, period=14):
    """คำนวณค่า RSI 14 เพื่อเลี่ยงการใช้ไลบรารีภายนอกที่อาจติดตั้งยาก"""
    deltas = np.diff(prices)
    seed = deltas[:period+1]
    up = seed[seed >= 0].sum() / period
    down = -seed[seed < 0].sum() / period
    rs = up / down if down != 0 else 0
    rsi = np.zeros_like(prices)
    rsi[:period] = 100. - 100. / (1. + rs)

    for i in range(period, len(prices)):
        delta = deltas[i - 1]
        if delta > 0:
            upval = delta
            downval = 0.
        else:
            upval = 0.
            downval = -delta
        up = (up * (period - 1) + upval) / period
        down = (down * (period - 1) + downval) / period
        rs = up / down if down != 0 else 0
        rsi[i] = 100. - 100. / (1. + rs)
    return rsi[-1]

def scan_momentum_stock(ticker):
    """ดึงข้อมูลและกรองสูตรเทคนิคอลเกรด A+ รายตัว"""
    try:
        stock = yf.Ticker(ticker)
        
        # --- [เงื่อนไขที่ 1] ตัวกรองพื้นฐาน (Basic Filters) ---
        info = stock.info
        market_cap = info.get("marketCap", 0)
        current_price = info.get("previousClose", 0) # ใช้ราคาล่าสุดโดยประมาณ
        
        # ตรวจสอบขนาดของบริษัท $300M - $3B และราคา >= $10
        if not (10 <= current_price) or not (300_000_000 <= market_cap <= 3_000_000_000):
            return  # ไม่ผ่านเกณฑ์พื้นฐาน ให้ข้ามทันที

        # --- [เงื่อนไขที่ 2] เทรนด์ภาพใหญ่ (Daily) ขาขึ้นเต็มตัว ---
        df_daily = stock.history(period="1y", interval="1d")
        if len(df_daily) < 200: return
        
        df_daily['EMA50'] = df_daily['Close'].ewm(span=50, adjust=False).mean()
        df_daily['EMA200'] = df_daily['Close'].ewm(span=200, adjust=False).mean()
        
        # เช็คราคาปิด > EMA50 > EMA200 ติดต่อกัน 3 วันล่าสุด
        condition_daily = all(
            (df_daily['Close'].iloc[-i] > df_daily['EMA50'].iloc[-i] > df_daily['EMA200'].iloc[-i])
            for i in range(1, 4)
        )
        if not condition_daily: return

        # --- [เงื่อนไขที่ 3] การทะลุกรอบ (20-Day Breakout) ---
        # หาจุดสูงสุดในรอบ 20 วันก่อนหน้า (ไม่นับแท่งวันนี้)
        past_20_days_high = df_daily['High'].iloc[-21:-1].max()
        last_close = df_daily['Close'].iloc[-1]
        if last_close <= past_20_days_high: return

        # --- [เงื่อนไขที่ 4] แรงส่งระยะสั้น (ไทม์เฟรม 15 นาที) ---
        df_15m = stock.history(period="5d", interval="15m")
        
        # [อุดรอยรั่ว Anti-NaN] ถ้าแท่ง 15 นาทีไม่ครบ 14 แท่ง ให้กดข้ามป้องกันคำนวณเออร์เรอร์
        if len(df_15m) < 14: return
        
        last_bar_vol = df_15m['Volume'].iloc[-1]
        avg_vol_5d = df_15m['Volume'].mean() # สถิติเฉลี่ยย้อนหลัง
        dollar_value = last_close * last_bar_vol

        # วอลุ่มแท่งล่าสุด ต้องพุ่ง >= 3 เท่า และมูลค่าการซื้อขายสะสมในแท่ง >= $50,000
        if last_bar_vol < (avg_vol_5d * 3) or dollar_value < 50000: return

        # คำนวณ RSI 15m เพื่อแนบเป็นข้อมูลดิบประกอบ
        rsi_15m = calculate_rsi(df_15m['Close'].to_numpy(), 14)

        # --- [เงื่อนไขที่ 5] ดึงข่าวสารล่าสุดพ่วงท้ายข้อความ ---
        news_title = "No recent news available."
        if stock.news:
            news_title = stock.news[0].get('title', news_title)

        # หากผ่านเกณฑ์ทั้งหมด ให้ประกอบข้อความแล้วยิงเข้า Telegram
        alert_msg = (
            f"🚀 [US MOMENTUM ALERT] 🚀\n"
            f"Stock: *{ticker}*\n"
            f"Price: ${last_close:.2f} (20-Day Breakout!)\n"
            f"Market Cap: ${market_cap/1_000_000:.1f}M\n"
            f"Volume 15m: {(last_bar_vol):,.00f} (>= 3x Avg)\n"
            f"RSI (15m): {rsi_15m:.1f}\n"
            f"-----------------------------\n"
            f"📰 *Latest English News Summary:*\n"
            f"_{news_title}_"
        )
        send_telegram(alert_msg)
        print(f"[+] Alert sent for {ticker}")

    except Exception as e:
        # [อุดรอยรั่ว Robust Logic] หากตัวไหนล่มให้ข้ามไปตัวถัดไปทันที ระบบห้ามพัง
        print(f"[-] Error scanning {ticker}: {e}")

# ==========================================
# 4. ฟังก์ชันหลักคุม Workflow (Double-Scan)
# ==========================================
def main():
    print("[*] Starting US Momentum Scanner...")
    
    # สแกนรอบที่ 1
    watchlist = get_top_10_active_stocks()
    for ticker in watchlist:
        scan_momentum_stock(ticker)
        
    # ตรวจสอบเงื่อนไขเวลาปิดตลาดนิวยอร์ก ก่อนจะเริ่มสแกนรอบสอง
    if is_market_closed_ny():
        print("[*] Market is closed in NY. Skipping second scan loop.")
        sys.exit(0)

    # [เทคนิค Double-Scan] หน่วงเวลา 2 นาทีครึ่ง เพื่อสแกนซ้ำรอบที่สองใน Workflow เดิม
    print("[*] Sleeping 150 seconds before the 2nd scan...")
    time.sleep(150)

    print("[*] Starting 2nd scan loop...")
    for ticker in watchlist:
        scan_momentum_stock(ticker)

if __name__ == "__main__":
    main()
